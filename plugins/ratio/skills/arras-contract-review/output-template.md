# Report template

Write the report in the user's language, with the headings and the labels below (Serious, Negotiable, Fine, What it says…) translated. The ratings have fixed translations in [references/regional-terms.md](references/regional-terms.md). Keep the order. Leave out a section only where the note says so.

---

## Review of the {document type} — {buyer's / seller's} side

> Orientative review, not legal advice. Take it to a lawyer before signing; the lawyer decides.

### 1. Applicable law

One short paragraph: the rule applied (e.g. "Catalan Civil Code, art. 621-8"), why (where the property is, as confirmed by the user), and what that changes. If no reference covers the jurisdiction, say so here.

### 2. Summary

Three to five bullets, the serious points first. One line each.

### 3. Clause by clause

One block per relevant clause, in the order of the contract:

**Clause {n}: {short name}** · {Serious / Negotiable / Fine}
- **What it says:** "{literal quote, shortened with […] if long; personal data replaced by [ID], [IBAN], [name]}"
- **What it means for you:** {risk in plain language, from the user's side}
- **Proposed wording:** "{alternative text}" (omit when Fine)
- **Basis:** {rule} — {origin}

Serious: the user can lose money or be forced into a sale they cannot complete, a legal requirement is missing, or the clause may be an unfair term under the applicable rules (for instance a penalty that binds only the consumer, in a sale by a business). Negotiable: unbalanced or vague, worth asking to change, not a deal breaker. Fine: correct and balanced; list them in one line at the end of the section rather than one block each.

### 4. What is missing

Each clause the contract should have and does not, with its seriousness and a proposed wording. Typical: arras type, financing condition, state of the property (charges, occupants, debts), deadline and notary for the deed, allocation of costs, off-plan guarantee, what happens to the deposit in each case.

### 5. What happens to your money

A table, from the user's side, with what the contract says or, if it is silent, what the applicable law gives:

| If… | The deposit… | And besides… |
|---|---|---|
| The buyer walks away | | |
| The seller walks away | | |
| The mortgage is refused | | |
| A party does not show up at the notary | | |
| The property has undisclosed charges or debts | | |

Add rows the contract makes relevant (off-plan delay, licence not granted).

### 6. Documents to ask for before signing

Bullets, each with one line of why. Take them from the reference file of the applicable law (in Catalonia, include the habitability certificate and, from a developer or agency, the written information they must give before any payment). Without a reference file (outside Spain, or a territory with its own law), give a general list: the land registry extract or its local equivalent, proof that there are no debts on the property, the identity and powers of whoever signs, and ask the local lawyer to confirm the local documents.

### 7. Questions for your lawyer

Numbered, concrete, specific to this contract. Include every point marked "not verified" and every point that depends on facts the user did not confirm.

### 8. Sources

Every rule cited above, once, with its origin:
- **Official source consulted:** {name, article} — {URL} — consulted on {date}
- **Reference file:** {name, article} — generated on {date}
- **Provided by the user:** {rule, as the user gave it}
- **Case law:** {line of case law} — specific judgments not verified
- **Not verified:** {statement}

Close with one line: what to redact if the user shares the contract further, only if the conversation showed personal data.
