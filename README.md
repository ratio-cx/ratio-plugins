# Ratio plugins

The marketplace that [Claude Cowork](https://claude.com/product/cowork) installs **Ratio** from: real estate tools for analysts, consultants and real estate professionals.

## Install Ratio in Cowork

1. In Claude Desktop, open **Customize > Plugins**.
2. **Add > Add marketplace**, enter `ratio-cx/ratio-plugins` and press **Sync**.
3. Open **Ratio** in the list and press **Add**.

## Updates

New versions arrive by themselves: Cowork syncs this marketplace with GitHub. To get one at once, press **Update** on Ratio's plugin page, or **Check for updates** in the marketplace's `···` menu.

## About this repository

It is generated: every release of Ratio replaces its content, and nothing here is edited by hand. `plugins/ratio/` is the plugin as Cowork receives it.
